# `scripts/` - developer utilities

Run all of these from the repo root, with the dev dependencies installed
(`pip install -r requirements-dev.txt`).

| Script | What it does |
| --- | --- |
| `benchmark.py` | Measures real CPU throughput (image, audio, TTS preview) and writes `docs/assets/benchmark_data.json`. |
| `generate_charts.py` | Renders the benchmark/coverage PNGs in `docs/assets/` from that JSON (Pillow only, no matplotlib). |
| `generate_samples.py` | Produces the real before/after demo media in `docs/assets/samples/` (image, 1-min audio, background removal when the u2netp model is present). |

```bash
python scripts/benchmark.py        # -> docs/assets/benchmark_data.json
python scripts/generate_charts.py  # -> docs/assets/*.png
python scripts/generate_samples.py # -> docs/assets/samples/*
```

Everything these scripts produce is generated by the actual backend functions -
none of the numbers or samples are hand-authored. See
[docs/benchmarks.md](../docs/benchmarks.md) and [docs/samples.md](../docs/samples.md).
